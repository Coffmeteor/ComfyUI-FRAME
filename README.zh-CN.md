# FRAME Nodes — ComfyUI / ComfyLink 工作流生成器

在电脑配置模型、LoRA 和提示词来源，生成简洁的操作工作流。可以直接在 ComfyUI 出图，也可以通过 ComfyLink 手机操作。不需要我们的 FRAME 应用或 FRAME Link 连接插件。

## 安装后怎么打开？

1. 在 ComfyUI Manager 搜索 **FRAME Nodes（frame-nodes）**，安装 **0.3.4**，重启 ComfyUI 并刷新浏览器。
2. 点击左上角 **ComfyUI 菜单 → FRAME → 配方设置**，直接打开生成器，不必先加载工作流。
3. 也可以加载包里的 **workflows/FRAME Krea2 - Start Here.json**，点击 **配置模型与 LoRA / Configure models & LoRAs**；两种方式打开的是同一个生成器。

如果 Manager 还没收录新版，可下载 **FRAME-Nodes-0.3.4.zip**，将里面的 **ComfyUI-FRAME** 文件夹解压到 **ComfyUI/custom_nodes/** 后重启，只保留一份。Manager 安装时会处理声明的依赖；手动安装到 Windows 环境时可能需要补充声明的时区数据依赖。Registry 上传成功不等于已经通过审核或完成索引。

## 在电脑上配置

1. 在「模型设置」选择本机的 Krea2 主模型、文本编码器和 VAE；发布包不包含模型权重。
2. 设置采样步数、采样器和调度器。默认 8 步、CFG 1、Euler ancestral / beta，按模型需要调整。
3. 在「我的 LoRA」添加分组、选择 LoRA 文件、填写手机显示名称，设置模型强度、CLIP 强度和应用阶段。仅作用于模型的 LoRA 使用 CLIP 强度 0。
4. 触发词可选自动、手动或不用。自动模式读取明确的元数据；没有元数据时填入作者提供的触发词。互斥分组勾选一次只允许开启一个。
5. 按需导入本地词库，选择界面语言和工作流标签语言，填写工作流名称及保存位置。
6. 点击「保存配方并生成手机工作流」，再点击「打开已生成工作流」。在生成的画布里选择提示词、LoRA 开关及强度、画质参数，即可运行。

## 在 ComfyLink 手机上使用

先在电脑安装并配对 ComfyLink 自己的连接插件。在 ComfyLink 面板上传刚生成的工作流，然后在手机同步并打开。保存配方时 FRAME Nodes 会尝试刷新已配对后端的节点定义；如提示失败，先刷新节点定义，再同步工作流。

0.3.4 的「批量抽词 · 数量与编号」卡片支持每次随机抽 1–10 条，或按固定编号列表选择。固定编号属于所选词库；原版与改写版各自编号。要复用当时的文本、种子和设置，使用已保存任务的重放码。种子与提示词编号是两件事。

LoRA 开关和模型强度可在手机调整；文件选择、CLIP 强度和触发词在电脑配置。已有配方不会被更新插件自动改写，需要重新生成并同步，才会出现新增控件。

生成的工作流依赖这台电脑保存的配方。分享给新用户时应提供生成器和入门文件，让对方选择自己的模型，而不是直接分享你的私人配方。

完整功能、可选依赖和重放限制见 [English guide](README.md)。
